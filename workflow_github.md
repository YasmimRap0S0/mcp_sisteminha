# Workflow Github

1. `$ pip install django` __instalando o Django__
1. `$ git clone https://github.com/tads-cnat/sisteminha.git` __clonando o repositório - primeiro acesso__
1. `$ git fetch` __atualizando as informações do repositório *git*__
1. `$ git checkout [branch da issue]`
1. `$ git pull`
1. __modificações nos artefatos__
1. `$ git add [lista dos artefatos modificados]`
1. `$ git commit -m "[comentário legível]"`
1. `$ git push`
